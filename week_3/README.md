## 파일 목록
- `number.c` : 숫자 맞히기 게임
- `sum.c` : 가변 매개변수로 합계 구하기
- `printNum.c` : 숫자 오름차순 작성하기
  
## 배운 내용 정리
- **number.c** : `scanf`로 사용자 입력을 받고, 난수(`rand`)와 비교해 반복문 안에서 정답을 맞힐 때까지 출력하는 방법을 배웠다.
- **sum.c** : `stdarg.h`의 `va_list`, `va_start`, `va_arg`, `va_end`를 이용해 인자 개수가 정해지지 않은 가변 인자 함수를 만드는 방법을 배웠다.
