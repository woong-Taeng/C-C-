## 파일 목록
- `dice.c` : 주사위 10번 던져서 눈금별 횟수 세기
- `score.c` : 점수 입력받아 구간별 인원수 세기
- `array1.c` : 값 전달과 배열 전달의 차이 확인하기
- `bubble.c` : 버블 정렬로 배열 오름차순 정렬하기
- `count_num.c` : 곱셈 결과의 각 자릿수 등장 횟수 세기

## 배운 내용 정리
- **dice.c** : 배열의 인덱스를 값으로 사용해서(`cnt[n]++`) 입력받은 숫자별 횟수를 세는 방법.
- **score.c** : 점수를 10으로 나눈 몫을 인덱스로 써서 구간별 인원수를 세는 방법.
- **array1.c** : 변수 하나를 넘기면 값만 복사되어 원본이 바뀌지 않지만, 배열을 넘기면 원본이 그대로 바뀐다는 값 전달과 배열 전달의 차이를 배웠다.
- **bubble.c** : 인접한 두 값을 비교해 자리를 바꾸는 과정을 반복하는 버블 정렬 알고리즘을 배웠다.
- **count_num.c** : 숫자를 10으로 나눈 나머지로 각 자릿수를 뽑아내고, 그 자릿수를 다시 배열 인덱스로 써서 등장 횟수를 세는 방법.
